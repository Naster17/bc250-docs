# Getting Started

Welcome to **BC250 Docs**. This page shows the basics: headings, links, lists, code and a table of contents on the right.

## What is covered

- [Hardware](/hardware/) - specs, pinouts, power, cooling
- [System](/system/8core-unlock/) - 8-core unlock, governor, sensors
- [Showcase](/showcase/) - every Nextra component in one place

## Quick start

```sh
git clone https://github.com/Naster17/bc250-docs
cd bc250-docs
npm install
npm run dev
```

Open `http://localhost:3000` and edit `app/getting-started/page.mdx`.

## Checklist

1. Read the [Hardware](/hardware/) overview
2. Follow the unlock guide in [System](/system/8core-unlock/)
3. Skim the [Showcase](/showcase/) to learn the syntax
